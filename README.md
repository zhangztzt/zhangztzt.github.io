# 铜管学长的黑大新生指南

一份面向黑龙江大学新生的纯静态综合服务指南。它把报到、住宿、食堂、快递、预算、数字校园、选课、大一节奏、社团人际、冰城生活与安全提醒整理成可以直接执行的步骤。

## 当前功能

- 23 个主题章节与 44 项可勾选行动清单
- 本地保存阅读与任务进度，不上传个人信息
- 站内搜索、深浅主题、打印 / 保存 PDF
- 桌面端与移动端响应式布局
- 减少动态效果适配与键盘可访问支持
- 黑龙江大学视觉元素与“铜管学长”主理人品牌

## 本地预览

直接双击 `index.html` 即可阅读。若希望以与线上一致的方式预览，可在项目目录启动任意静态文件服务器。

## GitHub Pages 发布

1. 新建一个公开 GitHub 仓库。
2. 将 `index.html`、`assets/`、`.nojekyll` 和本说明文件上传到仓库根目录。
3. 打开仓库的 `Settings → Pages`。
4. 在 `Build and deployment` 中选择 `Deploy from a branch`。
5. 选择 `main` 分支和 `/(root)` 目录并保存。
6. 等待 GitHub Actions 部署完成，再用 Pages 地址检查图片、搜索、主题、移动端和分享功能。

## 信息边界

本项目是非官方学生辅助指南。报到时间、收费、住宿、选课、场所开放和联系方式等动态信息，以黑龙江大学当年录取材料、学院通知和学校官方平台为准。页面中的官方图片目前保留来源说明；公开传播或二次使用前，应进一步确认相应授权边界。
